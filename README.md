# Germany Data Talent Intelligence Platform

## Business Problem

Fresh graduates and entry-level candidates in Germany often do not know which data, BI, and AI skills are most demanded by employers. Job descriptions are spread across many platforms and are difficult to compare manually.

## Project Objective

This project analyses German data-related job postings to identify in-demand skills, realistic entry-level roles, top locations, work models, and skill gaps for Data Analyst, BI Analyst, Junior Data Engineer, and AI/ML-related roles.

## Planned Tech Stack

- Python
- pandas
- SQL
- PostgreSQL
- Tableau
- GitHub
- Streamlit
- Docker

## Project Phases

1. Collect job postings
2. Clean job descriptions with Python
3. Extract required skills
4. Store data in PostgreSQL
5. Analyse trends with SQL
6. Build Tableau dashboard
7. Create job-matching app
8. Publish project on GitHub
